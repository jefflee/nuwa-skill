## 一、早期生平與教育（1930–1956）

### 🍼 出生與童年

| 年份 | 事件 |
|------|------|
| **1930年8月30日** | **Warren Edward Buffett 出生**於美國內布拉斯加州奧馬哈市，排行老二，三兄妹中唯一的兒子。父親 Howard Buffett 為美國國會議員及商人，母親 Leila（née Stahl）。就讀 Rose Hill Elementary School。 |
| **1937年（約7歲）** | 從奧馬哈公共圖書館借到《One Thousand Ways to Make $1000》，**深受啟發，商業天賦開始萌芽**。 |
| **童年期** | 開始最早的商業活動：**逐戶販售口香糖、可口可樂、週刊雜誌**；在祖父的雜貨店工作。 |
| **1941年（11歲）** | **買入人生第一支股票**：為自己和姐姐 Doris 各購買 3 股 Cities Service Preferred（每股約 $38.25）。股票先跌到 $27，巴菲特堅持未賣，等到回升至 $40 才獲利了結。後來該股漲至 $200，讓他學到「長期持有」的第一課。 |
| **1942年** | 父親當選國會議員（第一任，共四任），全家遷至華盛頓特區。Warren 就讀 Alice Deal Junior High School。 |
| **1944年（約13歲）** | **人生第一次報稅**：申報 $35 的腳踏車與手錶費用（送報紙路線的業務支出）。這是巴菲特有記錄的最早納稅申報。 |
| **1945年（高中二年級，約15歲）** | 與朋友花 $25 合買一台二手彈珠機放入理髮店，數月內擁有 3 家理髮店的多台彈珠機。**1947年以 $1,200 賣出——第一個規模化小生意**。 |
| **約15歲** | 送《華盛頓郵報》，**月收入超過 $175**（換算 2025 年幣值約 $3,130）。 |
| **約14歲** | 用存款 $1,200 買下一塊 40 英畝農地，租給佃農耕作——**人生第一筆房地產投資**。 |
| **1947年** | 於 Woodrow Wilson 高中畢業，畢業紀念冊寫道：「熱愛數學；未來的股票經紀人」。 |

---

### 🎓 大學時期

| 年份 | 事件 |
|------|------|
| **1947年** | 進入**賓夕法尼亞大學沃頓商學院（Wharton School）**，加入 Alpha Sigma Phi 兄弟會。（因父親要求，本人傾向直接做生意）。 |
| **1949年** | 轉學至**內布拉斯加大學林肯校區**。 |
| **1950年（約20歲）** | 以 20 歲之齡自大學畢業，獲得**商業管理學士（BS），主修投資管理**。累計存款達 $9,800（換算 2025 年幣值約 $132,608）。 |
| **1950年春** | **申請哈佛商學院——遭拒**。轉而申請哥倫比亞大學，得知 **Benjamin Graham（班傑明·葛拉漢）在此任教**後，立即入學。 |
| **1950–1951年** | 在**哥倫比亞商學院師從 Benjamin Graham**，習得「價值投資」體系：安全邊際、內在價值、市場先生等核心概念。同班同學 Walter Schloss 也成日後著名投資人。 |
| **1951年** | 獲哥倫比亞大學**經濟學碩士（MS）**學位。 |

---

### 💼 職涯起步

| 年份 | 事件 |
|------|------|
| **1951年** | 發現 Graham 是 **GEICO 保險**董事會成員。某個週六獨自前往華盛頓特區 GEICO 總部敲門，與副總裁 Lorimer Davidson 暢談保險業務數小時，**並買入人生第一批 GEICO 股票**。Davidson 後來成為巴菲特終生摯友，15 分鐘內就認定他是「非凡的人」。 |
| **1951年** | 前往**紐約金融學院（New York Institute of Finance）**深造。 |
| **1951–1954年** | 返回奧馬哈，在**父親的公司 Buffett-Falk & Co.** 擔任投資銷售員。同期修完 Dale Carnegie 公開演講課，並在**內布拉斯加大學奧馬哈分校**教授「投資原則」夜校課程（學生平均年齡是他的兩倍以上）。 |
| **1952年** | 與 **Susan Thompson 結婚**，於奧馬哈 Dundee 長老教會舉行婚禮。 |
| **1953年** | 長女 **Susan Alice** 出生。 |
| **1954年** | **獲 Benjamin Graham 聘用**，加入葛拉漢-紐曼公司（Graham-Newman Corp.），年薪 $12,000（換算 2025 年幣值約 $143,866）。與 Walter Schloss 共事，深度實踐「煙蒂股」投資法。 |
| **1954年** | 次子 **Howard Graham** 出生。 |
| **1956年** | **Graham 退休並關閉合夥公司**。此時巴菲特個人存款已超過 $174,000（換算 2025 年幣值約 $206 萬）。決定返回奧馬哈，自立門戶。 |

## 二、合夥公司時期（1956–1969）

### 🤝 建立投資王國

| 年份 | 事件 |
|------|------|
| **1956年5月** | **成立 Buffett Associates, Ltd.**（第一個合夥公司），資金 $105,000，其中巴菲特自己出資 $100。同年成立多個類似合夥企業。**投資哲學此時仍為純葛拉漢式**：只買遠低於帳面價值的「煙蒂股」。 |
| **1957年** | 經營 **3 個**投資合夥企業。 |
| **1958年** | 以 **$31,500** 在奧馬哈買下一棟五臥室灰泥房（**至今仍居住於此**）。 |
| **1959年** | 合夥企業增至 **6 個**。該年夏天，在奧馬哈俱樂部（Omaha Club）的商務午餐上，**首次遇見 Charlie Munger**（芒格）——改變彼此命運的相遇。 |
| **1961年** | 向合夥人披露：**35% 資金集中在 Sanborn Map 公司**（製作保險用地圖）。Sanborn 股價 $45，但投資組合價值 $65/股，地圖業務被市場「定價為負 $20」。巴菲特取得 23% 股份，進入董事會，聯合不滿的股東控制 44%，最終公司以高於市價回購 77% 流通股，**兩年獲利 50%**。 |
| **1962年** | **成為百萬富翁**，合夥企業合計管理約 $720 萬（個人份額逾 $102 萬）。將各合夥公司合併為 **Buffett Partnership, Ltd.** 一個實體。 |
| **1962年** | **開始在 $7.60/股 買進 Berkshire Hathaway**（一家新英格蘭紡織廠），原計劃等公司清算套利。 |
| **1964年** | ⭐**關鍵投資：American Express（美國運通）**。「沙拉油醜聞」（salad oil scandal）導致 AmEx 股價暴跌，市場恐慌。巴菲特反向大舉買入——此舉展現其「在恐慌中貪婪」的特質，也是他**脫離純葛拉漢框架的早期信號**：他觀察到 AmEx 的特許經營價值（品牌）遠超帳面價值。 |
| **1965年** | **取得 Berkshire Hathaway 控制權**，出任董事長，並任命 Ken Chace 為總裁管理日常業務。買入均價 $14.86/股，而公司運營資本為 $19/股。 |
| **1966年** | **關閉合夥公司對外募資**（市場開始過熱）。 |
| **1967年** | Berkshire 入股 National Indemnity 保險公司（$860 萬）——**第一筆保險業收購，奠定日後 Berkshire 帝國的核心模式**（保險浮存金用於投資）。Berkshire 同年發放**有史以來唯一一次股息（10 美分）**。 |
| **1969年** | 以「市場過熱、難找合理定價標的」為由，**正式解散合夥公司**。將資產分配給合夥人，包括 Berkshire Hathaway 股份。個人薪資：$50,000/年（換算 2025 年幣值約 $43.9 萬）。 |

## 三、Berkshire 轉型期（1970–1989）

### 🔄 從紡織廠到控股帝國

| 年份 | 事件 |
|------|------|
| **1970年** | **正式就任 Berkshire Hathaway 董事長兼 CEO**，開啟長達 55 年的掌舵生涯。 |
| **1972年** | ⭐⭐**收購 See's Candies（喜斯糖果）——思想轉型的關鍵時刻**！以 **$2,500 萬**收購，當時年營收約 $3,000 萬。這是 **Charlie Munger 強力說服**的結果。巴菲特本欲以更低價才買，芒格說服他：「付合理的價格買偉大的企業，勝過付低廉的價格買平庸的企業」。See's Candies 至 2019 年已為 Berkshire 帶回超過 **$20 億**利潤（原始投資 8000% 的回報），開啟巴菲特「品質投資」新紀元。 |
| **1973年** | 開始**買進《華盛頓郵報》股票**，與控制人 Katharine Graham 建立深厚友誼並加入董事會。 |
| **1974年** | SEC 就 Berkshire 收購 Wesco Financial 是否存在利益衝突展開正式調查——**最終未起訴**。 |
| **1976年** | ⭐**GEICO 危機時大舉買入**。GEICO 面臨財務困境（幾乎破產），股價暴跌。巴菲特大量買進，此後 Berkshire 持有 GEICO 股份持續增加，**到 1996 年完全收購**。 |
| **1977年** | 以 **$3,250 萬**購入《水牛城晚報》（Buffalo Evening News）。反壟斷官司纏鬥直至競爭對手《水牛城信使》1982 年停刊才告終。 |
| **1977年** | 與妻子 Susan **分居**（感情破裂），但維持婚姻關係直至 2004 年 Susan 去世。Susan 介紹 Astrid Menks 陪伴巴菲特。 |
| **1978年** | **Charlie Munger 正式加入 Berkshire，出任副董事長**。兩人合作深化，芒格的哲學（菲利浦·費雪式品質投資 + 多元思維模型）持續改造巴菲特的思想框架。 |
| **1979年** | 開始買進 ABC 電視台股票。 |
| **1983年** | 以 **$6,000 萬**收購 Nebraska Furniture Mart（內布拉斯加家具市場）。 |
| **1985年** | **Berkshire 最後一批紡織廠出售關閉**——徹底完成從紡織公司到控股集團的轉型。同年，協助 Capital Cities 以 $35 億收購 ABC（ABC 是 Cap Cities 的 4 倍大），換取合併後公司 25% 股份。 |
| **1986年** | 收購 Scott Fetzer 公司（32 個品牌集團，含百科全書等）。 |
| **1987年** | Berkshire 以 **12% 股份（最大股東）**入股 Salomon Inc. 投資銀行，巴菲特出任董事。**1987 年股市崩盤（黑色星期一）期間巴菲特保持沉默，未恐慌出售**——體現其長期主義。 |
| **1988年** | ⭐⭐**大舉買入可口可樂**：最終持有可口可樂約 **7% 股份，成本約 $10.2 億**（換算 2025 年幣值約 $27.7 億）。此後數十年成為 Berkshire 最賺錢的投資之一，至今仍持有。 |
| **1989年** | 以 Berkshire 資金 ~$670 萬購買私人飛機，命名「The Indefensible」（不可辯護），後改名「The Indispensable」（不可或缺）——引發外界對奢侈支出的批評，但他後來認為這是商業必需品。 |
| **1958年** | 次子 Peter Andrew 出生。（補充：家庭資料） |

## 四、Berkshire 成熟期（1990–2009）

### 🏰 帝國的試煉與擴張

| 年份 | 事件 |
|------|------|
| **1990–1991年** | ⭐**所羅門兄弟危機**：John Gutfreund（CEO）因放任交易員 Paul Mozer 違規投標美國國債（超額申報）而離職。**巴菲特臨危受命擔任所羅門臨時董事長**，向國會作證，力保公司保有美國政府客戶資格，最終化解危機。展現他的危機領導力，保護了 Berkshire 的大量投資。 |
| **1991年** | 收購 H.H. Brown Shoe Group。 |
| **1995年** | 收購 RC Willey Home Furnishings；偶遇中買下 Helzberg Diamonds。 |
| **1996年1月** | ⭐**完全收購 GEICO**：以 **$23 億**購入其未持有的 49% 股份。至此 20 年投資長跑圓滿，GEICO 成為 Berkshire 最核心的保險子公司。 |
| **1997年** | 以 **$5.85 億**收購 Dairy Queen（冰雪皇后）；收購 Star Furniture。 |
| **1997–1998年** | 購入 **1.297 億盎司白銀**（1997 年 7 月至 1998 年 1 月）——罕見的實物商品投資。 |
| **1998年7月** | 以 **$7.25 億**收購 NetJets（全球最大分時私人飛機服務商）。 |
| **1998年12月** | 以 **$220 億**收購 General Re 再保險公司（以 Berkshire 股票支付）——巴菲特後來承認定價過高，但 Gen Re 仍表現良好。 |
| **1999年** | ⭐**科技泡沫警告**：在《財富》雜誌（1999年11月）發表著名文章，警告投資者股市回報預期過高。**拒絕投資任何科技股（包括亞馬遜、Google 等）**，短期內遭受媒體嘲諷，被認為「老了、跟不上時代」。但隨後 2000–2002 年崩盤證明他是對的。 |
| **1999年** | 收購 MidAmerican Energy Holdings（能源基礎設施）；Jordan's Furniture。 |
| **2001年** | ⭐**衍生品的警告**：在股東信中首次發出警告，稱衍生品為「**定時炸彈**」。2003 年在股東信中再度升級批評，稱金融衍生品為「**大規模金融毀滅性武器（financial weapons of mass destruction）**」。2008 年金融危機印證此預言。 |
| **2002年** | 首次進入外匯市場：以 **$110 億**簽訂遠期合約，押注美元走弱；2006 年獲利超過 $20 億。 |
| **2004年7月** | **妻子 Susan Thompson Buffett 去世**，享年 72 歲（因中風）。Susan 的遺產 $26 億主要捐入 Buffett Foundation。 |
| **2006年6月** | ⭐**宣布最大規模慈善捐贈計劃**：將 **85% 的 Berkshire 股份分批捐出**，主要受益者為比爾與梅琳達·蓋茲基金會（BMGF）——當時史上最大慈善捐贈。宣布後立即開始，每年 7 月捐出 5% 份額。 |
| **2006年8月30日** | 在 76 歲生日，**與長期伴侶 Astrid Menks 結婚**（她自 1977 年 Susan 離開後與巴菲特同居）。 |
| **2007年** | 公開表示正在尋找「更年輕的接班人」，開始部署 CEO 繼任計劃。聘入投資經理 Todd Combs（2010 年）和 Ted Weschler（2011 年）協助管理投資組合。 |
| **2007–2008年** | ⭐**金融危機的反向操作**：當市場恐慌時，巴菲特主動出擊：
- **2008年9月23日**：以 50 億美元認購 Goldman Sachs（高盛）10% 永久優先股（含 10% 股息及認股權證）
- **2008年10月**：以 30 億美元買入 General Electric（奇異）優先股
- 在《紐約時報》發表著名評論：「**Buy American. I Am.**（買美國，我正在買）」
- 在 Q3 2008，Berkshire 盈利下滑 77%，被批評「投入太早」，但長期回報豐厚 |
| **2008年** | 一度成為**全球首富**（身家 $620 億，超越比爾·蓋茲）。 |
| **2009年** | 以 **$340 億（含債務 $440 億）**完成**收購 Burlington Northern Santa Fe（BNSF 鐵路）**——美國最大的私人鐵路投資，Berkshire 史上最大收購案。 |
| **2009年** | 承認 ConocoPhillips（康菲石油）投資是個錯誤——在油價高位大量買入，油價暴跌後損失數十億。 |
| **2010年** | BNSF 正式並表。與 Bill Gates 及 Mark Zuckerberg 共同簽署「**Giving Pledge（捐贈誓言）**」，承諾捐出超過 50% 財富，並邀請全球億萬富翁響應。 |

## 五、近年動態（2010–2023）

### 🍎 從排斥科技到擁抱蘋果

| 年份 | 事件 |
|------|------|
| **2011年** | ⭐ 宣布買入 **IBM 股票** $110 億（約 5.5% 股份）——此前巴菲特多次聲稱不懂科技股、不會買。此舉令市場震驚。（然而，IBM 後來表現不佳，最終 2017 年賣出，幾乎無獲利）。 |
| **2011年** | 以 $2 億收購《奧馬哈世界先鋒報》，組建 BH Media Group 媒體集團（2020 年最終出售媒體資產給 Lee Enterprises）。 |
| **2011年** | 奧巴馬總統授予他**總統自由勳章**（Presidential Medal of Freedom）。 |
| **2012年4月11日** | 例行檢查中確診**第一期前列腺癌**，宣布將接受 44 天放射線治療。在股東信中表示感覺「很好，精力 100%」。 |
| **2012年9月15日** | 宣布完成放射線療程，稱「這是我很棒的一天」。 |
| **2012年** | 收購 Media General 旗下 63 家報紙（以美國東南部為主），合計擁有 30 家以上日報。 |
| **2014年8月** | Berkshire A 股股價首度突破**每股 $200,000 大關**，公司市值達 $3,280 億。 |
| **2015年** | Berkshire A 股（BRK.A）屢創新高，成為**全球每股股價最高的上市公司**（Buffett 一貫反對股票分割）。 |
| **2016年** | ⭐⭐**開始買入蘋果（Apple）股票**（第一季，由投資經理 Todd Combs 首先建倉）。巴菲特評估蘋果不是科技公司，而是擁有近乎無可取代品牌忠誠度的**消費品公司**——這是他最重要的一次思想突破。此後持續加倉，蘋果成為 Berkshire 第一大持倉。 |
| **2016年** | 公開挑戰 Donald Trump 公布稅務申報表，巴菲特同時公開自己的稅單（2015 年稅率約 16%），指出巴菲特法則（Buffett Rule）的稅制不公問題。 |

## 七、投資哲學演變：三大思想轉折點

### 🔄 轉折點一：葛拉漢「煙蒂股」→ 芒格「品質優先」
（1959年相識芒格 → 1972年 See's Candies 完成轉變）

**轉變前（純葛拉漢時代）**：
- 核心邏輯：只買「以 50 分的價格買價值 1 元的東西」
- 不在乎企業品質——只要夠便宜
- 典型案例：Berkshire Hathaway 本身（廉價但品質差的紡織廠）
- 巴菲特稱 Berkshire 是「人生中最大的投資失誤」

**芒格的影響**（1959年後逐漸）：
> "It's far better to buy a wonderful company at a fair price than a fair company at a wonderful price."
> — Charlie Munger

**轉變後（See's Candies 的頓悟，1972年）**：
- 以 $2,500 萬收購一個「帳面上並不便宜」但品牌力極強的企業
- 開始理解「**護城河（moat）**」和「**定價權**」的重要性
- 後來也更理解費雪（Philip Fisher）的「成長型價值投資」框架

---

### 🔄 轉折點二：排斥科技股 → 擁抱蘋果
（1999年科技泡沫警告 → 2016年開始買蘋果）

**轉變前**：
- 「我不投資我不懂的行業」——著名的能力圈（circle of competence）概念
- 1999–2000 科技泡沫中，拒絕投資所有網路科技股（亞馬遜、Google、Yahoo 等）
- 2011 年 IBM 投資是「半步」嘗試，但最終以虧損收場

**蘋果的洞見（2016年）**：
- 巴菲特重新框架 Apple：它不是「科技公司」，而是擁有**超強品牌黏著度的消費品公司**
- 用戶換手機成本極高（生態系鎖定）= 超強護城河
- 用他理解 See's Candies 的邏輯來理解 Apple：顧客願意為品牌溢價
- 後來稱蘋果是「**Berkshire 最好的投資**」（Better than See's Candies, better than Coca-Cola）

**結果**：
- 巔峰時持有約 9 億股 Apple，市值約 $1,700 億（佔 Berkshire 股票組合近 40-50%）
- 2024 年減倉至約三分之一，但仍為最大單一持股

---

### 🔄 轉折點三：個人資本時代 → 保險浮存金的槓桿洞見
（1967年收購 National Indemnity → 完善體系）

**核心洞見**：
- 傳統投資需要用自己的錢
- 保險公司先收取保費（「**浮存金（float）**」），在理賠前可免費使用這筆資金進行投資
- 若承保紀律嚴格（不過度承保），浮存金幾乎是「負成本資本」
- Berkshire 最終建立起以**保險浮存金為核心的複利飛輪**
